Rust timings cover handler work through response assembly, excluding final JSON encoding and network transit. The browser round trip includes the request and JSON parsing. These timings describe this request, not a language comparison.

Why changing location is fast

The Axum service initializes SGP4 constants once for each catalog entry. It keeps a bounded cache of immutable orbit samples and GeoJSON, so changing the observer reuses propagation and recalculates only ground geometry. Custom TLEs bypass this cache. Tokio sends numerical work to blocking workers; concurrent predictions are bounded.

Built to explore

A prediction, with context.

Explore six historical examples: ISS, Vanguard, polar, navigation, geostationary, and Molniya orbits. Each has its own element epoch; these paths do not represent the satellites today. You can also supply your own TLE.

Earth rotation is approximated using GMST with UTC in place of UT1, and polar motion is omitted. This is an exploration tool, not live telemetry or a navigation service.
